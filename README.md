# 清屏 v1.0.0

一款安卓小工具：别的 App 弹出开屏广告时，自动帮你点“跳过”；不小心点到广告跳去淘宝、京东、浏览器时，自动按返回拉回来。按 App 统计拦截次数，都在软件里看得到。

**先说清楚它做不到什么（别被名字误导）：**
安卓不给普通 App“不让广告加载”的权限，所以广告还是会闪一下（一般 0.5～3 秒），清屏是抢在你前面点跳过，不是让广告完全不出现。没有“跳过”按钮的广告、倒计时没走完的广告、摇一摇广告，可能会漏掉。没有 Root，也杀不掉别的 App、断不了它的广告网络。

**隐私：不联网，不上传。** 本 App 不申请 INTERNET 权限，统计只存在手机本地数据库里。

---

## 功能（v1）

- 自动点“跳过”：无障碍服务监听窗口变化，找到“跳过 / 跳过广告”按钮就点掉，每个 App 1 秒内最多点一次防重复。
- 误触拦截：2 秒内从开屏广告突然跳到淘宝、京东、拼多多、美团或浏览器，就自动按返回，并记 1 次误触拦截。
- 按 App 统计：首页显示今日总数、累计总数；每个 App 一行，有图标、名字、今日 / 累计次数、单独开关（默认全开），点一行看最近 7 天。
- 保活：常驻前台服务（通知栏挂“清屏正在运行”）+ 开机自启 + 忽略电池优化引导。

## 安装后必须手动做的 4 件事

只装 App 不设置，重启、清后台、开省电后服务都会停。**无障碍服务系统不允许代码自动开，必须你手动开。**

### OPPO Find X8 Pro / ColorOS 16（优先按这个来）

1. 打开清屏 → 点“去开启无障碍服务”→ 在系统无障碍列表里找到“清屏”，打开开关。
2. 设置 → 应用管理 → 清屏 → 耗电管理 → 允许后台运行。
3. 设置 → 应用管理 → 自启动管理 → 允许清屏自启动。
4. 打开最近任务（从底部上滑停住），找到清屏的卡片，下滑点锁形图标，把清屏上锁。
5. 电池优化里设为不优化：清屏“保活设置”页点“设为不优化”，按提示选允许；或手动进 设置 → 电池 → 应用耗电管理 → 清屏 → 不优化。

做完回清屏首页，看到“无障碍服务：已开启”就好了。ColorOS 16 不同小版本菜单名字可能略有差别，找不到时在设置顶部直接搜“自启动”“耗电管理”“电池优化”。

### 其他品牌（在 App 内“保活设置”页也有）

- 小米：应用管理 → 清屏 → 自启动允许；电池 → 应用省电管理 → 无限制；最近任务上锁。
- 华为 / 荣耀：应用管理 → 允许自启动；电池 → 应用耗电管理 → 手动管理 → 三个允许全开；最近任务上锁。
- vivo：权限管理 → 自启动允许；电池 → 后台耗电管理 → 允许后台高耗电；最近任务上锁。
- 三星：应用程序 → 清屏 → 电池 → 允许后台活动；电池 → 后台使用限制 → 永不休眠的应用 → 添加清屏。

## 打包方法

### 方法 A：GitHub Actions（推荐，不用在本机搭环境）

1. 把本工程推到 GitHub 仓库。
2. 打开仓库的 Actions 页，等 `Build debug APK` 跑完。
3. 在那次运行里下载 `qingping-debug-apk`，得到 `app-debug.apk`，传到手机安装。
4. 手机安装时要开“允许安装未知来源应用”，这是侧载 App 的正常提示。

### 方法 B：本机打包

需要 JDK 17 + Android SDK（API 35 已装好，`local.properties` 里写 `sdk.dir=你的 SDK 路径`）：

```bash
./gradlew assembleDebug --no-daemon
```

APK 在 `app/build/outputs/apk/debug/app-debug.apk`。

> 注意：如果本机是受限沙箱，Gradle 守护进程走本机回环 TCP 可能被拦而失败，这是环境限制不是代码问题，改用方法 A。

## 技术说明

- 包名 `com.qingping.app`，应用名“清屏”，minSdk 26，targetSdk 34，Kotlin + Jetpack Compose + Room。
- 核心是 `QingpingAccessibilityService`：监听 `TYPE_WINDOW_STATE_CHANGED` / `TYPE_WINDOW_CONTENT_CHANGED`，遍历节点找文本、描述或控件 id 含“跳过”的可点节点，只点跳过，不点广告本体。
- 开关存在 SharedPreferences（无障碍回调里要同步读，不能等数据库），统计存在 Room（`qingping_stats.db`，按包名 + 日期记）。
- 前台服务类型是 `specialUse`（Android 14+ 强制要求声明；Android 16 对部分类型加了超时，specialUse 不受影响）。targetSdk 保持 34，不为 ColorOS 16 / Android 16 升到 36。

## 常见问题

- **装完广告还在闪一下？** 正常，清屏是点跳过不是拦截加载，0.5～3 秒的闪现去不掉。
- **有的广告没跳过？** 可能是没跳过按钮、倒计时没完、按钮是图片没文字，v1 认不出来。
- **重启 / 清后台后不工作了？** 先看首页无障碍是不是还开着，再按上面保活 4 件事补设置；无障碍掉了要手动重开。
- **通知栏一直挂着“清屏正在运行”？** 故意留的，删掉它服务容易被系统杀掉。
